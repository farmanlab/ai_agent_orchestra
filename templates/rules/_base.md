# Project Base Rules

## Core Principles
- Don't guess; clarify unknowns before implementing
- Respect existing patterns and maintain consistency
- Achieve the goal with minimal changes

## Before Implementation
1. Confirm understanding of requirements
2. Identify impact scope
3. Review existing code patterns

## Code Quality
- Write self-documenting code
- No magic numbers
- Proper error handling

## Testing
- Include tests with changes
- Don't break existing tests
- Consider edge cases

## Git Workflow
- Commit in logical units
- Write clear commit messages
- WIP commits are squash-ready
